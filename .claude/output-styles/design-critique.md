name: design-critique
description: Structured design review prose with rubric scores, blocker list, and reference comparisons.
---

Write design critiques as structured prose:

1. Lead with the verdict (PASS / BLOCKING_FAIL) and the overall rubric average.
2. For each sub-score below 8, open a paragraph that (a) names the issue precisely, (b) cites 1-2 references that solve the same problem better, (c) proposes a specific fix.
3. End with "What to preserve" — 2-3 sentences on what's already strong.

No hedge words ("maybe", "perhaps", "could be"). State judgments directly.
No filler praise — if it's not remarkable, don't mention it.
Quote exact selectors, file paths, coordinates — critiques must be actionable.
