# Сравнительный анализ архитектур AI-агента для n8n workflow automation

> Документ для принятия архитектурного решения при создании автономного AI-агента,
> ориентированного на разработку, анализ и оптимизацию n8n workflows.

## Критерии оценки

- **Автономность**: 1 (полностью ручной) → 5 (полностью автономный)
- **Эффективность кода**: способность работать с JSON, expressions, nodes
- **Итоговая оценка**: 0-10 баллов с учётом всех факторов

## Матрица решений по сценариям

| Сценарий использования | Рекомендуемая архитектура | Альтернатива | Обоснование |
|------------------------|---------------------------|--------------|-------------|
| **Личное использование / эксперименты** | Single-agent (LLM-only) | RAG-enhanced | Минимум setup, достаточно для обучения и простых задач |
| **Стартап / небольшая команда** | Agent + Tool Router | Agent + deterministic rules | Баланс функциональности и сложности |
| **Enterprise / compliance** | Agent + deterministic rules | Human-in-the-loop | Гарантии, аудируемость, governance |
| **Code-heavy workflows** | Agent + sandboxed execution | Multi-agent | Проверка кода до production критична |
| **DevOps / SRE** | Event-driven agent | Agent + memory | Проактивный мониторинг и автохилинг |
| **Долгосрочный проект** | Agent + memory + eval loop | RAG-enhanced | Накопление знаний о проекте |
| **Platform / Agency** | Orchestrated microagents | Multi-agent | Максимальная масштабируемость и гибкость |

## Рекомендация по умолчанию

Для большинства production-сценариев рекомендуется **комбинация**:

```
Agent + Tool Router + deterministic rules engine + sandbox (optional)
```

Это даёт:
- Автономность через tools
- Гарантии через rules
- Проверку через sandbox (для критичного кода)
- Управляемую сложность

**Итоговая формула выбора:**

```
Если (compliance критичен) → добавить rules engine
Если (код сложный) → добавить sandbox
Если (нужен мониторинг) → добавить event-driven компонент
Если (долгосрочный проект) → добавить memory
Если (команда большая) → добавить human-in-the-loop для критичных операций
```
