# Industry Conventions (Guardrails, not Rules)

Each industry has shibboleths users expect; violating them without purpose feels "off".

## Fintech
- Navy + trust-blue + green accent default. Avoid red as primary.
- Sans with high x-height (legibility on tables).
- No playful mascots. Minimal motion.
- Compliance badges visible.

## SaaS (B2B)
- Product shot above fold is expected.
- Feature bento, 3-6 cards.
- Usage metrics (customers, uptime) in hero region.
- Dark mode expected; dev-tooling audiences prefer default-dark.

## DTC (consumer goods)
- Hero color + cream/off-white neutral.
- Product photography over illustration.
- Personality in voice — can be playful.
- Review counts visible; social proof dense.

## Creator tools
- Can go iridescent / shader / expressive.
- Motion permitted.
- Community rails (Discord, gallery) above fold often.

## Gov / Legal / Education
- WCAG AAA expected, not AA.
- High-contrast mode toggle.
- Longer body copy accommodated (serif for reading, sans for navigation).
- No hype language.

## Healthcare / Wellness
- Warm neutrals + sage/terracotta OK.
- Rounded corners; soft shadows acceptable.
- Readable at senior accessibility levels.

## Infra / DevOps
- Mono type appropriate. Code snippets in hero common.
- Deep neutrals; electric/neon accent.
- Terminal-like microinteractions acceptable.
