# Visual Trends 2025–2026 (with forecast to 2027)

## Summary
Flat-brutalism and Swiss-grid remain dominant in SaaS marketing through 2026; expressive serifs and variable-font experimentation are growing in consumer/DTC. Glass/neumorphism is niche and industry-conditional (fintech, wellness). Anti-design is near saturation — differentiate on craft, not just style.

## Key concepts
- Oversized editorial typography with optical-size variable axes
- Scroll-pinned heroes with letter-by-letter reveals (GSAP SplitText)
- Noise/grain textures as ambient layer (CSS filter or seamless PNG)
- Asymmetric bento grids replacing 3-up feature rows
- OKLCH-based dark mode (perceptually calibrated)
- Ambient WebGL backgrounds (low-poly, glsl-noise) — only when budget allows
- Restrained motion: one statement motion per page, not five

## Actionable rules
1. If `industry === 'fintech' || 'wellness'`, glass/neumorphism is permissible; elsewhere, avoid.
2. Variable fonts over static — prefer families with `wght` and `opsz` axes.
3. Do not ship gradient blobs unless brief explicitly calls for playful.
4. Reserve hero motion for brands where it maps to product story.
5. Grain/noise texture budget: ≤ 1 instance per page.
