# Awwwards Teardowns

Each teardown captures the section patterns, motion approach, and typographic choices from notable sites. Used by `section-composer` and `motion-director` to reference real-world implementations.

## File format
Each teardown is `<year>-<site-slug>.md` with:

```
## Site
URL, year, award, category
## Hero
Pattern (scroll-pinned | shader | editorial), motion lib, approximate JS budget
## Sections
Ordered list with archetype tags from section catalog
## Type
Display / text / mono, licensing
## Color
Primary palette in OKLCH
## Motion signature
What's memorable, where it succeeds or fails
## Pattern tags
Tags from tag-vocab.md
## What we'd steal
1-3 specific patterns with application notes
```

Run `/retrospective` against the first 3 engagements to seed initial teardowns. Target: 30 teardowns by end of Milestone 3.
