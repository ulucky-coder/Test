# Brand Archetypes (Jung / Pearson 12 + Aaker 5)

## Summary
Archetypes bridge abstract brief language to concrete visual/voice decisions. Every client gets a primary + secondary scored 0–1 so the mapping is inspectable.

## The 12 (Pearson)
| # | Archetype | Core desire | Cue words | Visual vocabulary |
|---|---|---|---|---|
| 1 | Innocent | safety, simplicity | pure, honest, nostalgic | soft pastels, rounded, serif |
| 2 | Sage | truth, understanding | precise, evidence, knowledge | high-contrast, monospaced, grid |
| 3 | Explorer | freedom, discovery | bold, rugged, adventurous | earthy, textured, outdoor |
| 4 | Outlaw | revolution | disruptive, raw, rebellious | brutalist, clashing, aggressive |
| 5 | Magician | transformation | visionary, mystical, catalytic | iridescent, fluid, gradient |
| 6 | Hero | mastery | courageous, strong, triumphant | bold sans, high contrast, warm reds |
| 7 | Lover | intimacy | sensual, graceful, romantic | elegant serif, jewel tones |
| 8 | Jester | enjoyment | playful, spontaneous, witty | vivid, rounded, display |
| 9 | Everyman | belonging | down-to-earth, authentic | muted, humanist sans |
| 10 | Caregiver | service | nurturing, compassionate | soft, warm, accessible |
| 11 | Ruler | control | authoritative, refined, prestigious | serif, deep neutrals, gold |
| 12 | Creator | innovation | imaginative, expressive, crafted | editorial, custom type, bold |

## Aaker personality (blend with Pearson)
Sincerity · Excitement · Competence · Sophistication · Ruggedness

## Scoring rules
- Each of 12 scored 0–1 from brief tokens against cue-word lexicons.
- Primary = top; secondary = #2 if delta to #3 > 0.1, else blend.
- If primary < 0.55, brief is too vague — surface to `brand-strategist`.

## Archetype → visual implications (seed rules)
- **Sage** → no gradients in body; monospace display OK; diagrams over photos; no drop shadows.
- **Creator** → custom type acceptable; editorial scale; asymmetric layout OK.
- **Ruler** → serif display; deep neutrals; gold/brass accent cap; centered layouts.
- **Outlaw** → brutalist grid; mono or default system fonts; clashing color OK; grain texture.
- **Jester** → display weight, variable axes, saturated palette, bouncy motion.
- **Magician** → shader/iridescent OK for flagship tier; gradient mesh acceptable.
- **Caregiver** → rounded corners, soft shadows, WCAG AAA, warm palette.
