# Brand Guidelines Playbooks — Reference

## Pentagram / FutureBrand mold
- Narrative-led: story → logo → color → type → application
- Heavy on do/don't imagery
- Print-first but includes digital spec
- Length: 60–120 pages

## Modern open-source systems
- **IBM Carbon**: token-driven, fully digital, versioned
- **Mozilla Protocol**: component-first, accessibility baked in
- **GOV.UK**: accessibility/voice-forward, legal tone
- **Shopify Polaris**: dev + design parity, playground
- **Atlassian**: brand + voice + product unified

## Atelier's structure (hybrid)
1. One-page brand story (Pentagram style) — emotional opener
2. Token reference tables (Carbon style) — machine-readable
3. Component gallery — Polaris style
4. Voice playbook — GOV.UK style (examples, not rules)
5. Motion + imagery — Stripe Press style

## Output channels
- Interactive web doc at `clients/<slug>/site/guidelines/*`
- Printable PDF (A4 portrait)
- Figma Library (optional, premium+)
- `tokens.json` bundled for vendor handoff
